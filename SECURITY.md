# Security Policy

## Supported Versions

Only the latest active development line of OpenTaskbar receives security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

The OpenTaskbar project takes security and user privacy seriously. If you discover a security vulnerability, please report it privately rather than opening a public issue.

### Preferred Reporting Method
Please use the **[GitHub Private Vulnerability Reporting](https://github.com/alztrk/opentaskbar/security/advisories/new)** feature:
1. Navigate to the **Security** tab of this repository.
2. Click **Report a vulnerability** under Security Advisories.
3. Provide a detailed summary, reproduction steps, and potential impact.

### What to Include in Your Report
To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept demonstrating how to reproduce it.
- The version of OpenTaskbar, Windows build number, and architecture.
- Any mitigation or patch suggestions you might have.

### Response Timeline
- **Initial Response:** We aim to acknowledge receipt of your report within 48 hours.
- **Triage & Status Updates:** We will keep you informed of the validation progress and intended remediation timeline.
- **Coordinated Disclosure:** We kindly request that you give the maintainers reasonable time to address the issue before any public disclosure.
